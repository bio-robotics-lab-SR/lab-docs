# Suggest a change

These docs are maintained by *name of the docs maintainer*, who publishes all changes. That keeps the pages consistent and stops them drifting apart.

## Spotted something wrong or missing?

Send a short message by email or Teams to *name and contact of the docs maintainer* with:

- **Which page**, for example "Thymio → Troubleshooting"
- **What's wrong or missing**
- **The text you suggest**, if you have it. Ready-to-use text gets published fastest.

## Who provides the content

| Content | Who provides it |
|---|---|
| A robot system page | The owning PI, with the system champion |
| Shared infrastructure pages | The lab engineer, via the lab coordinator |
| Help levels and lab rules | Agreed in the quarterly lab-ops meeting |

PIs and champions are asked to check their system's page once a quarter and send any corrections. The *Last reviewed* date at the top of each system page shows when that last happened.
